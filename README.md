A microwave oven reports the one fault it can never fix: its uneven heating. The edges come out lava, the middle stays ice, and the machine calls the result a success. One honest error line, at most 200 characters, for make.fun's "The Funniest Honest Appliance Error" bounty.

## Run it

```sh
python3 main.py
```

This writes `entry.txt` (one line) to `/output`, or to `$MAKEFUN_OUTPUT_DIR` when set. Requires Python 3.13; standard library only, no network.
